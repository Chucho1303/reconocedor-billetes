## Descripción

Completar y validar las plantillas de $100, $200 y $500 para que el motor reconozca las seis denominaciones.

## Situación actual (revisión del repositorio)

- `Back/plantillas/100/`, `200/` y `500/` ya contienen fotografías, pero siguen los archivos `AGREGAR_FOTOS.txt` que piden fotos reales.
- Las pruebas (`test_plantillas_disponibles` y `test_cada_plantilla_se_reconoce_a_si_misma`) solo cubren $20, $50 y $1,000.
- `Back/plantillas/200/` tiene 2 fotos y `500/` tiene 2, frente a 3 de $20, $50 y $100.

## Criterios de aceptación

- [ ] Cada carpeta (`100`, `200`, `500`) tiene fotografías reales del billete completo, tomadas con buena luz.
- [ ] Se eliminan los `AGREGAR_FOTOS.txt` una vez cubiertas las fotos.
- [ ] `test_plantillas_disponibles` verifica las seis denominaciones.
- [ ] `test_cada_plantilla_se_reconoce_a_si_misma` se parametriza con `[20, 50, 100, 200, 500, 1000]`.
- [ ] Al menos una foto de ejemplo por denominación nueva se reconoce correctamente con confianza ≥ umbral.
- [ ] `python Back/billetes.py evaluar Back/plantillas` reporta la exactitud por denominación y queda registrada.
- [ ] El estado de esta tarea cambia a «Hecho» en `Ejecucion/docs/BACKLOG.md`.

## Cómo verificar

```bash
python -m pytest -v -c Ejecucion/pytest.ini
python Back/billetes.py evaluar Back/plantillas --csv evaluacion.csv
```
