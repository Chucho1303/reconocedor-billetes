# #3 · Plantillas reales de $20, $50 y $1,000

| Campo | Valor |
|---|---|
| **Estado** | Hecho |
| **Tipo** | `feat` |
| **Alcance** | `back` |
| **Responsable** | _por asignar_ |
| **Rama sugerida** | `feat/3-plantillas-20-50-1000` |

## Descripción

Cargar fotografías reales de los billetes de $20, $50 y $1,000 como plantillas de referencia del motor.

## Criterios de aceptación

- [x] Existen `Back/plantillas/20/`, `Back/plantillas/50/` y `Back/plantillas/1000/` con fotografías reales.
- [x] `cargar_plantillas()` lee las carpetas por denominación y las devuelve listas para `clasificar`.
- [x] Cada plantilla se reconoce a sí misma como su propia denominación.
- [x] La carpeta de plantillas puede cambiarse con la variable `BILLETES_PLANTILLAS`.

## Cómo verificar

```bash
python -m pytest -c Ejecucion/pytest.ini -k "plantilla"
```
